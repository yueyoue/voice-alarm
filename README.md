# 语音闹钟（Voice Alarm）

一个专为**老人和视力不佳者**设计的安卓闹钟：多闹钟、自定义提醒文字、可调超大字号、**滑动解除**、**语音朗读提醒内容**。

> 纯 Java + Android 框架 API 实现，**无任何第三方依赖**，APK 由 GitHub Actions 自动构建。

## 功能

- **多条闹钟**：可添加任意条闹钟，每条独立开关，列表按时间排序，顶部显示"下一次闹钟"。
- **自定义提醒文字**：每条闹钟可写一段提醒内容，例如"吃降压药，然后去公园散步"。
- **可调字号**：每条闹钟可选 标准 / 大 / 特大 / 超大（1.0x → 2.2x），列表、编辑预览、响铃全屏页同步放大；设置里还有"新闹钟默认字号"。
- **滑动解除**：闹钟响起时为全屏大字界面，**必须向右滑动滑块**才能停止闹铃，返回键无效，避免误触关闭。
- **语音朗读**：使用系统 TTS 中文引擎朗读提醒文字，响铃时播报，并每 45 秒重复一次直到解除。
- **语音开关**：设置页有语音提醒总开关，每条闹钟也可单独开关语音。
- **重复星期**：可指定每周一至周日任意组合重复，不选则只响一次。
- **可靠响铃**：`AlarmManager.setAlarmClock` 精确闹钟（系统唤醒白名单），前台服务循环播放闹铃 + 震动 + 自动把闹钟音量调到最大。
- **自动恢复**：开机、应用更新、系统时间/时区变更后自动重新排定所有已开启闹钟。

## 安装

1. 在 [Releases](../../releases) 下载最新 `voice-alarm-*.apk`。
2. 手机打开该 APK，允许"安装未知来源应用"。
3. 首次打开按首页黄色提示条开启 **精确闹钟**、**通知**、**全屏通知** 权限（Android 12 以上必需）。

## 使用要点

- 闹钟响起后必须**向右拖动底部滑块**才能关闭，点按或返回键不会关闭。
- 语音播报依赖系统中文语音包，若无声：系统设置 → 语言与输入 → 文字转语音 → 安装/选择中文引擎。
- 应用内已内置**「教程」页面**（首页右上角「教程」，或 设置 → 使用教程），内含各品牌后台权限配置步骤，并可一键跳转系统自启动管理页或本应用详情页。

## 手机权限设置（小米 / 红米，闹钟不响最常见的原因）

三处设置要一起改，只改其中一处，多数机型仍会清理后台：

1. **允许自启动**：设置 → 应用设置 → 授权管理 → 自启动管理 → 找到「语音闹钟」→ 打开开关；同页「关联启动管理」建议全部禁止。
2. **省电策略改成「无限制」**（最关键）：设置 → 省电与电池 → 右上角齿轮 → 应用省电策略 → 语音闹钟 → 无限制。也可长按桌面图标 → 应用信息 → 省电策略 → 无限制。
3. **后台任务加锁**：从底部上滑进入多任务界面 → 长按本应用卡片 → 点小锁图标。

补充：

- **通知**：设置 → 应用设置 → 应用管理 → 语音闹钟 → 通知管理 → 全部打开，并允许悬浮/横幅；Android 14 及以上还需「全屏通知」权限。
- **精确闹钟 / 电池优化**：首页黄色提示条开启「精确闹钟」；设置 → 特殊权限 → 电池优化 → 语音闹钟 → 不优化。
- **版本对照**：HyperOS 2/3 与 MIUI 12–14 入口基本一致；老版 MIUI 用「安全中心 → 应用管理 → 权限 → 自启动管理」「安全中心 → 省电模式 → 应用智能省电」。
- **常见坑**：开启省电模式会统一限制后台；开发者选项里若设过「后台进程限制」需改回「标准限制」；不要频繁一键清理后台（反复冷启动更耗电，也更容易杀掉闹钟）。
- **其他品牌**：华为/荣耀找「应用启动管理」；OPPO/一加/realme 找「应用耗电管理 → 允许后台运行」；vivo/iQOO 找「后台耗电管理 → 允许后台高耗电」；三星找「后台使用限制 → 永不休眠的应用」。

## 自行构建

```bash
# 需要 JDK 17 + Android SDK 34
gradle :app:assembleDebug
# 产物：app/build/outputs/apk/debug/app-debug.apk
```

或直接推送代码到 GitHub，`.github/workflows/build.yml` 会自动构建并上传 APK 产物。

## 技术实现

| 模块 | 说明 |
| --- | --- |
| `Alarm` / `AlarmStore` | 闹钟数据模型与 SharedPreferences(JSON) 持久化 |
| `AlarmScheduler` | `setAlarmClock` 精确排定、下一次触发时间计算、权限检查 |
| `AlarmReceiver` / `BootReceiver` | 到点广播、开机与时间变更后重排 |
| `AlarmService` | 前台服务：循环闹铃、震动、TTS 朗读、全屏通知 |
| `RingActivity` | 全屏响铃页，大字显示提醒内容 |
| `SlideToDismissView` | 自定义"向右滑动解除"控件（Canvas + ValueAnimator） |
| `MainActivity` / `EditAlarmActivity` / `SettingsActivity` | 列表、编辑、设置界面 |
| `GuideActivity` | 应用内使用教程：各品牌后台权限配置步骤 + 系统自启动/应用详情直达 |

最低支持 Android 6.0（API 23），目标 API 34。
